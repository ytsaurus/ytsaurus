# Особенности оформления документации YT

Этот файл содержит проектные правила для написания и редактирования документации YT.
Общие требования к тексту и оформлению задаёт [стайлгайд Infradocs](../../../../../docs/yateam/infradocs/).
Правила ниже дополняют его и имеют приоритет при расхождении с общими рекомендациями.
Применяй их также при проверке текста по стайлгайду.

## Текст и оформление

- В русском тексте используй букву `ё` там, где её требует орфография.
  Замена на `е` недопустима. Это правило относится и к заголовкам и подписям;
  написание команд, URL, имён параметров и других технических идентификаторов сохраняй.
- В тексте статьи, заголовках и метаданных страницы (`frontmatter`, например
  `title` и `description`) используй `{{product-name}}` вместо названий `YT`
  и `YTsaurus`. Не заменяй названия внутри кода, команд, путей, URL
  и технических идентификаторов.

## Терминология

Используй термины и варианты перевода из [глоссария YT](glossary.md).
Для SPYT дополнительно используй [глоссарий SPYT](../../../ru/_includes/user-guide/data-processing/spyt/glossary.md).
При расхождении с общими рекомендациями стайлгайда приоритет имеет проектный глоссарий.
