# AI-артефакты документации YT

Этот каталог содержит материалы для работы агентов с документацией YT.
Они не публикуются вместе со статьями. README предназначен для людей:
он объясняет устройство каталога и помогает поддерживать материалы.

## Что где лежит

| Каталог | Назначение | Материалы |
| --- | --- | --- |
| `reference/` | Проектные правила и опорные сведения для работы с текстом | [Правила оформления](reference/writing-rules.md), [целевая аудитория](reference/target-audience.md), [глоссарий](reference/glossary.md) |
| `codebase/` | Карта реализации YT и данные для проверки её актуальности | [Карта кодовой базы](codebase/codebase-map.md), [инвентарь каталогов](codebase/codebase-map-inventory.json) |
| `skills/` | Инструкции по выполнению конкретных задач | [Проверка сборки документации](skills/validate-doc-build/SKILL.md) |

Скилл написания документации `write-yt-doc` находится в Infradocs и подключается
через [AI Suite](../../aisuite.yaml). Ссылки на доступные скиллы и условия их
использования перечислены в [инструкциях проекта](../../AGENTS.md).

## Как подключаются материалы

Условия чтения материалов агентами задаются в [AGENTS.md](../../AGENTS.md),
инструкциях скиллов и [конфигурации AI Suite](../../aisuite.yaml).
При переносе файла обновляйте эти подключения и ссылки на него.
README не нужно добавлять в автоматически загружаемые инструкции.

Глоссарий используется и агентами, и автоматическим переводом документации.
Его путь указан в двух настройках `glossary_path` в [a.yaml](../../a.yaml).
Поддерживайте один файл терминов; требования к их применению описаны в правилах
оформления, а подробные объяснения не нужно добавлять в таблицу переводов.

## Как поддерживать карту кодовой базы

Карта редактируется вручную. В JSON-инвентаре список `top_level_directories`
формируется скриптом [check_codebase_map.py](../tools/check_codebase_map.py).
Поле `reviewed_on` обозначает дату ручной содержательной проверки карты:
перенос файлов или обновление списка каталогов не меняют эту дату.

Из корня Аркадии можно проверить карту и возраст её последней ревизии:

```bash
./ya tool python3 yt/docs/ai/tools/check_codebase_map.py \
  --repo-root . --max-review-age-days 90
```

Порядок обновления инвентаря и фиксации содержательной ревизии описан в
[разделе о поддержании актуальности карты](codebase/codebase-map.md#поддержание-актуальности-карты).

## Как расширять структуру

Распределяйте материалы по назначению, а не по частоте изменений.
Примеры с объяснением «до → после» можно добавить в `reference/examples/`.
Для обоснований решений и ответов на повторяющиеся вопросы предусмотрен `kb/`.
Создавайте эти каталоги вместе с первыми материалами.
