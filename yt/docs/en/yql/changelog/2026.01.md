## Window function changes {#window-functions}

Added support for `RANGE` mode in [window](../syntax/window.md) frame definitions.

## Built-in function changes {#built-in-functions}

Added the `PositionOf` function that lets you retrieve node positions.
Added the `WithIssue` function that lets you include a custom diagnostic frame in the validation stack.
Added the `AsOptional` function for idempotently wrapping a value in `Optional`.

## PostgreSQL module changes {#postgresql-module}

Added the ability to handle warnings as errors using `SET`, similarly to `PRAGMA Warning` in YQL syntax.
