## NYT::NFlow::TYdbTopicDriverConfig {#NYT_NFlow_TYdbTopicDriverConfig}

Источник: [yt/yt/flow/extensions/ydb/cpp/ydb_topic_driver.h]({{source-root}}/yt/yt/flow/extensions/ydb/cpp/ydb_topic_driver.h)

Настройки ресурса `TYdbTopicDriver` для подключения публичных коннекторов YDB. Встроенный ресурс передаёт данные без шифрования по адресу `host:port`. Настроек TLS и сертификата CA нет; `grpcs://` не включает TLS. Аутентификация по токену или логину и паролю не шифрует соединение.
