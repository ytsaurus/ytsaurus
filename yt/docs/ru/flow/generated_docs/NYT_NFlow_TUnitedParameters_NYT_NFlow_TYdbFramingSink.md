|| `attributes_column` | **Тип**: `std::optional<std::string>`
Колонка с yson-мапой пользовательских атрибутов `{имя -> строка}`, которые записываются в атрибуты сообщения YDB рядом с `flow_queue_meta_name`. Значение удобно собирать функцией `NYT::NFlow::PackYdbTopicAttributes()`: она проверяет зарезервированные имена и ограничения метаданных сообщения. Sink повторно проверяет итоговую мету перед отправкой сообщения.

Если параметр не задан или значение колонки равно `null`, пользовательские атрибуты не пишутся. Имена Flow (префикс `_ytflow_` и устаревшее `flow_queue_meta`) и имена с префиксом `__`, которые интерпретирует YDB, запрещены. Исключение — `__key`: YDB использует его как ключ Kafka-записи, поэтому атрибут разрешён. При включённой мете Flow пользовательский атрибут не может совпадать с `flow_queue_meta_name`. Framing sink-и отвергают `attributes_column`, потому что у сообщения YDB, собранного из нескольких сообщений Flow, нет однозначного набора атрибутов. ||
|| `max_memory_usage_bytes` | **Тип**: `long`
**Значение по умолчанию**: `52428800`
Лимит памяти сессии записи YDB для сообщений, ожидающих отправки. ||
|| `flow_queue_meta_name` | **Тип**: `std::string`
**Значение по умолчанию**: `_ytflow_queue_meta`
Имя атрибута сообщения YDB, в который sink записывает мету Flow. Читающий пайплайн должен использовать то же имя. ||
