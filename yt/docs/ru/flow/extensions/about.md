# Расширения {{product-name}} Flow

Расширение — необязательная интеграция пайплайна с внешней системой. Расширения могут предоставлять сорсы, синки и другие возможности пайплайна.

{% note info %}

Встроенные коннекторы для объектов {{product-name}}, таких как очереди и таблицы, описаны в разделе [Коннекторы](../connectors/about.md).

{% endnote %}
